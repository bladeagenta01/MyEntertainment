About this pilot

AI research uses the provider and API key you configure. Search history is not retained. Saved reference information stays in this browser and is attached to future research requests.

Settings

Operating mode and usage profile

Testing Mode limits research depth and input size. Production Mode restores the full depth range and larger request limits.

This profile is a label you choose. The app cannot inspect your provider billing balance or prove that a request is free. Provider-side billing and spend limits remain the final financial safeguard. Do not enable provider billing solely to make this pilot work.

Off by default. When off, the app blocks AI generation tests and research requests. When on, you authorise requests that may use any available free quota or promotional credits first, but could incur charges if those are unavailable or exhausted. The app cannot read your provider balance or guarantee a free request. Check provider billing and disable auto-recharge with your provider if you want to avoid automatic purchases.

Search runs separately from Gemini, OpenAI or Anthropic. Search has its own provider, key and usage limits. It does not use the AI provider's built-in grounding/search tool.

The search key is stored in this browser only after a successful search test. It is sent over HTTPS to Cloudflare for that request and forwarded to Tavily. It is not intentionally stored or logged by the backend. Browser storage is not encrypted.

AI connection

Your key is stored separately for each provider in this browser after a successful connection test. It is sent over HTTPS to the Cloudflare Pages backend, which forwards it to your selected AI provider for that request. The backend does not intentionally store, log or cache your key. Browser storage is not encrypted. Use a trusted device.

Test & Save Key checks authentication only. Test AI Generation sends a small request without live web search. A successful key test does not prove that research generation or search grounding has available quota.
